# Instructions for AI agents

1. Read docs/constitution.md before any change. It is binding.
2. Read the documents listed in your task. The repository, not the chat, is the source of truth.
3. Work only within the scope of the task. Do not implement ERP features unless the task asks for it.
4. Record findings that affect the project in the repository (docs/, ADRs, runbooks), not only in the chat.
5. Never commit secrets, personal data, Oracle proprietary artifacts or large binaries. Never use floating tags such as latest.
6. Stop and report briefly (do not decide) on architectural changes, data-loss risk, sensitive credentials, major scope changes or significant trade-offs between alternatives.
7. Solve simple operational problems yourself.
8. Run the validation commands of the task before finishing. Tests are part of the work.
9. Commits: Conventional Commits in English, small and coherent, with the Task:/Spec: trailers.
10. Final report: short summary of what changed, validation results, commit hashes and open questions. Do not paste long logs.
